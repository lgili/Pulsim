    Device reference¶

    One section per device kind. Key is the builder argument and the components() params key; the YAML registry entry (type: <kind> with pins:) and with_value("<device>.<name>") use Name. Bound is checked by with_value (not on a branch-form switch's own values), bind_param / set_param and the YAML registry reader (a derived field such as R is checked as the field it is stored as, G), each naming the device and the field; the add_* methods keep their own checks (some accept more: a negative resistor, m = 0, an ideal switch's g_off = 0). Default is the model's default (the value-initialised parameter set; "-" where that value is outside the bound, i.e. there is no usable default). Builder is the add_* method's own handling: required, same (its default equals the model's), its own default when it differs, not an argument, or ? (no readable signature: a Python wrapper). A field marked derived is stored as another field (R as G = 1/R); one marked in components() is listed in CircuitBuilder.components() params (the scalars it always listed); Circuit.devices() lists every field.

    Builder: CircuitBuilder.add_resistor.

    Name Key Unit Bound Default Builder Description
    R R_ohms Ohm a finite number > 0 - required resistance (stored as G = 1/R) (derived, in components())
    G S a finite number > 0 - not an argument conductance 1/R
