# PulsimCore Reference Projects

This folder holds **didactic reference projects** that pair worked-out
mathematical models with Pulsim simulations.

The goal is twofold:

1. **Educational.** Each project walks through the derivation step by
   step — equations are written out in LaTeX inside the notebook, the
   Python code mirrors the math one-for-one, and assumptions are stated
   explicitly. The audience is undergraduate / first-year graduate
   students learning power electronics for the first time.

2. **Cross-validation.** Every analytical model is validated against a
   Pulsim transient or AC sweep run side-by-side. When the analytical
   step response and the Pulsim transient overlay within tolerance, we
   have confidence in *both* the model AND the simulator.

## Layout

```
projects/
  converters/                            # DC-DC + DC-AC + AC-DC converters
    buck/                                # ← start here (simplest topology)
      00_buck_pulsim_validation.ipynb    # Pulsim cross-validation (EXECUTED — figures inline)
      01_buck_modeling.ipynb             # average model + state-space + transfer functions
      02_buck_controller.ipynb           # PI/type-III compensator + closed-loop
      buck_model.py                      # shared analytical model functions
      buck_pulsim_validation.py          # Pulsim helper used by the validation notebook
      README.md
    boost/                               # same layout: 00_pulsim, 01_modeling, 02_controller
    buck_boost/                          # same layout
    flyback/                             # same layout (isolated, transformer)
    forward/                             # same layout (isolated, buck-derived)
    half_bridge/                         # same layout (isolated, dual-switch)
    boost_pfc/                           # AC mains → boost PFC (DCM + CCM)
  inverters/
    vsi_3phase/                          # DC → 3-phase AC, SPWM + SVPWM + grid-tie
    npc_3phase/                          # 3-level NPC inverter — first multilevel topology
    mmc/                                 # Modular Multilevel Converter (single-phase, N=3 SMs/arm) — scalable HVDC-grade
```

Each project folder has the same three-notebook structure:

- **`00_<topo>_pulsim_validation.ipynb`** — Pulsim cross-validation,
  pre-executed and committed with figures. GitHub renders the
  waveforms directly — no need to install Pulsim or run a kernel.
  Generated by `_build_pulsim_validation.py`; helper code lives in
  `<topo>_pulsim_validation.py`.
- **`01_<topo>_modeling.ipynb`** — analytical derivation (KVL/KCL →
  averaging → state-space → transfer functions). Pure numpy/scipy.
  Generated by `_build_notebooks.py`.
- **`02_<topo>_controller.ipynb`** — compensator design (Type-II/III
  via K-factor), discretisation (Tustin), and a hand-rolled
  forward-Euler closed-loop sim. Generated by the same builder.

## How to run

The notebooks expect a Python environment with:

```bash
pip install numpy scipy matplotlib jupyter
pip install -e .                       # for the Pulsim cross-validation notebooks
```

Each notebook is self-contained — open it, run all cells top to
bottom. The `00_<topo>_pulsim_validation.ipynb` notebooks are
**already executed and committed with figures**, so you can view
them on GitHub without installing anything.

To regenerate any project's three notebooks from their source `.py`
builders:

```bash
python3 projects/converters/buck/_build_notebooks.py
python3 projects/converters/buck/_build_pulsim_validation.py
SKBUILD_EDITABLE_VERBOSE=0 jupyter nbconvert --to notebook --execute --inplace \
    projects/converters/buck/00_buck_pulsim_validation.ipynb
```

## Conventions

- **Symbols.** Lowercase = instantaneous (`v_o`, `i_L`). Uppercase = DC
  steady-state (`V_o`, `I_L`). Hat = small-signal perturbation
  (`v̂_o`, `î_L`, `d̂`).
- **State vector** ordering for every converter: passive currents first
  (inductor currents), then passive voltages (capacitor voltages).
- **Input vector** ordering: control inputs first (duty cycle d̂),
  then disturbance inputs (line voltage v̂_g, load step î_load).
- **State-space matrices**: `(A, B, C, D)` — `D` is the direct
  feed-through matrix (not the duty cycle).
- **Units**: SI throughout (V, A, Ω, H, F, s, Hz).

## What "validated" means here

Every project ships a dedicated `00_<topo>_pulsim_validation.ipynb`
that:

1. Builds the converter in [Pulsim](https://github.com/lgili/Pulsim)
   using the same parameters as the analytical model
   (`CircuitBuilder` + `make_pwm_switch_fn` + `simulate` + the
   `pulsim.topology` helpers for composite blocks).
2. Runs the switched transient at the design duty / modulation index.
3. Reports the DC steady-state value, output ripple, and (where
   applicable) the small-signal step response.
4. Overlays the Pulsim waveform on the analytical prediction so any
   mismatch is visible immediately.

These notebooks are committed **with executed outputs**, so on
GitHub you see the waveforms inline without running anything. If
you do run them locally and the two curves disagree, either the
converter parameters or the linearisation assumptions need to be
revisited.
