## What the numbers do not cover

- Circuits without a truth: 28 of the 109 reference circuits; they are graded by the strict gate only. 12 are refused by name by the truth engine (`benchmarks/EXACT_TRUTH.md`, coverage table): cl_boost_pi (closed loop / control block (pi_controller)); cl_buck_aggressive_pi (closed loop / control block (pi_controller)); cl_buck_pi (closed loop / control block (pi_controller)); ll14_buck_closed_loop (Shockley diode D_buck); ll15_boost_closed_loop (Shockley diode D_boost); ll16_flyback_closed_loop (Shockley diode D_sec); mosfet_nmos_dc (mosfet (Newton device) M1); ll12_pfc_boost_continuous (Shockley diode D_rec1); buck_mosfet_nonlinear (mosfet (Newton device) M1); ll08_buck_mosfet (mosfet (Newton device) M1); ll11_llc_resonant_converter (Shockley diode D1); ll13_active_clamp_forward (Shockley diode D_fwd). 16 are in its scope but have no truth record in `benchmarks/truth/` (not computed; no reason recorded): diode_clamp_overvoltage, ll02_rc_pulse_charge, ll03_rl_step, pulse_voltage_rl, rc_step, rl_step, two_stage_rc_lowpass, coupled_inductor_step, inductor_chain_step, lc_resonant_tank, ll04_rlc_underdamped, rlc_overdamped_step, rlc_parallel_step, rlc_step, stiff_two_timescale_rc, snubber_rc.
- Only what the engine records is graded (its stored rows, event instants and one-sided limits): what a trace does between its samples is not measured.
- Platform: every number here was measured on macOS (arm64, CPython 3.13); Linux and Windows are covered by CI tests, not by these artefacts.
- The release profile is not the default: `+next` columns apply it through the harness (`benchmarks/tools/next_defaults.py`); a plain `simulate()` call does not get it. Its branch form reaches `add_switch` / `add_diode` called with the netlist's values only (not MOSFET / IGBT helpers, Shockley diodes or calls with extra arguments). `+next` also applies the `PLAN` library defaults (`next_defaults.plan_defaults`); the scoreboard cells pass the netlist dt, so the `output_rtol` listed for `dsed+next` there is ignored (the rule runs only without dt).
- The analytic set (closed forms) is in `NEXT_DEFAULTS_REHEARSAL.md`, not in the tables above.
